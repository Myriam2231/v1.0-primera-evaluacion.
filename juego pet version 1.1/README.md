## como copilar y ejecutar este archivo 

 primero tenemos que ver que version de java hay instalada en el pc para saber la compatibilidad 

 se puede hacer de dos formas :
   - por la terminal :
         abrimos el terminal del sistema y ponemos " java -version " ,asií nos dira que version esta instalada 
   - por el uso de un entorno de desarollo (visual studio):

         abriremos el programa de visual studio y presionamos las teclas "ctrl" "shift" "p"
            en la barra que nos aparecerá ponemos : > "Java : Configure Java Runtime" y nos saldrá la version que tenemos de java 

ya sabiendo la version podemos copilar el programa

Abrimos la terminal y buscamos la carpeta en donde tengamos el proyecto del video juego  en este caso se encuentra en la carpeta scr del proyecto (podemos ver el interiror de la carpeta poniendo "dir" en la terminal )

   - ya estando en la carpeta escribimos el comando "javac App.java" y se nos copilara el juego 

   - para asegurarnos podemos escribir otro "dir" en la terminal; y se nos tendra que haber creado un archivo terminado en ".class"

   - ya asegurandonos que ha copilado correctamente , escribiremos "java App" y se nos ejecutara el video juego
